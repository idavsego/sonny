# Проверки перед деплоем

Прогонять **каждый раз** перед выкладкой приложения. 42 проверки интерфейса
и 16 проверок бэкенда, включая поломки: недоступный сервер, лимит запросов,
мусор в ответе, запрещённое хранилище.

## Приложение (42 проверки)

```
node tests/fake-backend.mjs &        # заглушка бэкенда на порту 8788
node tests/app.test.mjs              # прогон в Chromium
kill %1
```

Нужен playwright. Если он установлен глобально:

```
PLAYWRIGHT_MODULE=/opt/node22/lib/node_modules/playwright/index.mjs node tests/app.test.mjs
```

Что покрыто: онбординг и сохранение, полный цикл трекера (подъём → засыпание →
перезагрузка → пробуждение → запись в дневник), все вкладки, чат без
настроенного бэкенда, рабочий чат, ответы 429 и 500, отказ модели, мусор вместо
JSON, пустой ответ, недоступный адрес, запрещённый localStorage.

## Бэкенд (16 проверок)

```
cd server && npm install
ANTHROPIC_API_KEY=sk-ant-test PORT=8799 ALLOWED_ORIGINS="https://sonny.ru" TRUST_PROXY=0 node chat.mjs &
bash ../tests/server.test.sh
kill %1
```

Ключ может быть нерабочим: проверки до обращения к модели от него не зависят.

Что покрыто: доступ по домену (свой, чужой, без Origin), preflight, тело
больше лимита, битый JSON, недопустимые роли и пустой текст, отрицательный
`max_tokens`, чужая модель, лимит запросов с подменой `X-Forwarded-For`.

## Что эти тесты НЕ проверяют

Реальный ответ модели — для этого нужен рабочий ключ. Проверено отдельно:
запрос доходит до Anthropic и возвращает `401` на нерабочем ключе, то есть
путь исправен.
