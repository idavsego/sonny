# База знаний «Сонни» для контента

Obsidian-vault для курса «Контент-завод Pro». Лежит в git — значит переживает смерть компа.

## Как открыть

1. `git clone git@github.com:idavsego/sonny.git`
2. Obsidian → Open folder as vault → выбрать папку `baza-znaniy`

## Перенос на новый компьютер

Ничего не экспортировать. Поставить Obsidian, выполнить два шага выше — база на месте вместе со всей историей правок.

## Правило, чтобы не терялось

После каждой рабочей сессии:

    git add -A && git commit -m "база знаний: что изменил" && git push

Пока не сделан `push`, изменения живут только на этом компьютере.

## Структура

- `1. Контекст` — фундамент: ЦА, метод, продукты, стиль, арсеналы структур
- `2. Сбор данных` — свои посты и посты конкурентов
- `3. Аналитика` — разборы своего контента и конкурентов
- `4. Производство` — темник, виральные темы, сетка, готовый контент, сырьё
