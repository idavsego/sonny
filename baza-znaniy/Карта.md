## Контекст (фундамент для писателей)

- [[Профиль ЦА]] — для кого пишем. **Не заполнен** → скилл `issledovanie-ca`
- [[Распаковка экспертности]] — авторский метод и табу. **Черновик из приложения** → скилл `raspakovka-ekspertnosti`
- [[Сетка продуктов и оффера]] — что продаём и за сколько. **Не заполнен** → скилл `inventorying-product-line-and-offers`
- [[Мой стиль для разных каналов]] — голос по каналам. **Черновик из приложения** → скилл `stil-golosa-po-postam`
- [[_ПРОЧТИ — откуда взять структуры|Структуры контента]] — арсеналы структур из курса, нужно скопировать
